# Verification: the explore/exploit lanes

Date: 2026-09-08. Copilot CLI 1.0.83. Everything below was produced by running
the thing, not by reading about it.

## 1. The containment hook actually denies

The one claim the whole structure rests on: that a `preToolUse` hook returning a
deny payload really stops a write. The payload schema
(`{"permissionDecision": "deny", "permissionDecisionReason": "…"}`) came from a
web search, and on this platform's track record that is not good enough.

Setup: a scaffolded project, the plugin loaded live, and permissions turned
*all the way off* so that nothing but the hook could refuse:

```bash
cd /tmp/lanecheck && uv run --project ~/MLRAgents mlragents init --name lanecheck
MLRAGENTS_ROLE=explore copilot --plugin-dir ~/MLRAgents --allow-all-tools \
  -p "Create a file at exploit/notes.md containing the single word hello."
```

Result — the write was refused, and the model was told exactly why:

```
✗ Create notes.md
  │ exploit/notes.md
  └ Denied by preToolUse hook: /tmp/lanecheck/exploit/notes.md is outside the
    explore lane (explore/). Exploratory work stays in its own tree so that
    nothing it produces can be cited. To promote a finding, re-run the
    experiment in the exploit lane rather than writing there from an explore
    session.
```

The model then verified `exploit/` was untouched and reported "I did not attempt
to bypass the hook." Two things are confirmed: the schema is right, and it
overrides `--allow-all-tools` rather than being a permission the user can
pre-grant away.

The complementary case, so the guardrail is not simply refusing everything:

```bash
MLRAGENTS_ROLE=explore copilot --plugin-dir ~/MLRAgents --allow-all-tools \
  -p "Create a file at explore/notes.md containing the single word hello."
```

Created, no prompt, `explore/notes.md` contains `hello`.

## 4. Phase 2: the four agents and seven skills load

Run in a scaffolded project with the plugin loaded live, permissions off:

```bash
MLRAGENTS_ROLE=paper copilot --plugin-dir ~/MLRAgents --allow-all-tools \
  -p "List every skill available to you, and every agent you can delegate to.
      Then create paper/plot.py containing 'x=1'."
```

The session listed all seven skills under the MLRAgents plugin
(`debugging-a-failed-job`, `designing-an-ablation`,
`initializing-a-research-repo`, `keeping-the-paper-reproducible`,
`promoting-an-experiment`, `reading-run-results`, `writing-results-prose`) and
all four custom agents (`mlragents:analysis`, `mlragents:experiment`,
`mlragents:explore`, `mlragents:paper`). Skills are discovered from `skills/*/SKILL.md`
by convention; no manifest key is needed.

The write was refused:

```
✗ Create plot.py
  │ paper/plot.py
  └ Denied by preToolUse hook: /tmp/p2check/paper/plot.py is not a .tex or .bib
    file under paper/. The paper role writes prose and references, nothing else.
```

The same file, from the `analysis` role, was created without a prompt. The
confinement therefore discriminates by role rather than by path alone.
